# Huellitas de Amor

Proyecto web de una clínica veterinaria para la gestión de mascotas y usuarios.

- Samanta Lievano

## Como ponerlo a funcionar

1. Copiar la carpeta del proyecto en `C:\xampp\htdocs\`
2. Iniciar Apache y MySQL desde XAMPP.
3. Importar la base de datos desde phpMyAdmin.
4. Configurar la conexión a la base de datos de forma local.
5. Abrir el proyecto desde `http://localhost/huellitasdeamor/`
